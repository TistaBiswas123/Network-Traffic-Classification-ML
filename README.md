# Network Traffic Classification Using Machine Learning

Project Description

This project focuses on classifying network traffic using Machine Learning algorithms. It uses network traffic data to identify different types of network protocols.

Dataset

The project uses network traffic data collected from YouTube Live traffic. The dataset was used for analysis and model training. The dataset file is not included in this repository.

Machine Learning Algorithms Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

Model Accuracy

Algorithm| Accuracy
Logistic Regression| 91.55%,
KNN| 99.15%,
Decision Tree| 98.81%,
Random Forest| 99.48%.
